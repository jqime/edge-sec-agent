Flujo de una petición HTTPS:

  Cliente externo
      │
      │  GET https://<ip>:8443/api/metrics
      ▼
  [Nginx:8443]
      │  - Handshake TLS 1.2/1.3
      │  - Verifica Basic Auth (admin:password)
      │  - Rate limiting (5 req/s)
      │  - Añade security headers
      │
      │  proxy_pass → http://127.0.0.1:5000
      ▼
  [Gunicorn:5000]
      │  - Flask procesa la ruta
      │  - Llama a agent.py para métricas
      ▼
  [SQLite DB]
      │  - Lee última métrica (get_latest)
      │  - Retorna JSON con score, SSH failures, etc.
      ▼
  Respuesta ← Nginx ← Gunicorn ← Flask ← Cliente
