Flujo de una petición HTTPS:

  Cliente externo
      │  GET https://<ip>:8443/api/metrics
      ▼
  [Nginx:8443]  TLS 1.2/1.3 → Basic Auth → rate limit → security headers
      │  proxy_pass → http://127.0.0.1:5000
      ▼
  [Gunicorn:5000]  Flask procesa la ruta → agent.py (métricas del sistema)
      │
      ▼
  [SQLite]  get_latest() → JSON con score, ssh_failures, open_ports, temp, RAM
      │
      ▼
  Respuesta ← Nginx ← Gunicorn ← Flask ← Cliente
